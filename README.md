# Taskora — SaaS Landing Page

Taskora is a responsive landing page concept for an AI-powered productivity and task-management platform. It is designed for students, freelancers, and teams who want to organize projects, prioritize tasks, and track their progress.

This project was created as a Front-End Development Internship assignment.

## Features

- Responsive navigation bar with smooth scrolling and a mobile menu
- Hero section with calls to action and a productivity-dashboard preview
- Six feature cards:
  - AI Task Prioritization
  - Smart Scheduling
  - Real-Time Collaboration
  - Productivity Analytics
  - Automated Workflows
  - Secure Cloud Workspace
- Three-step “How It Works” section
- Three illustrative pricing plans: Free, Pro, and Team
- Contact form with client-side validation and a simulated success state
- Footer with section navigation and social-platform links

## Technology Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React icons

## Getting Started

### Prerequisites

Install Node.js and npm on your computer.

### Install dependencies

Open a terminal in the project folder and run:

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Vite will display a local URL in the terminal, usually:

```text
http://localhost:5173/
```

Open that URL in your browser. Keep the terminal running while you use the development site.

## Production Build

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```

Vite will display a local preview URL in the terminal. Keep that terminal window open while viewing the preview.

## Contact Form Note

The contact form demonstrates front-end form handling and client-side validation. Submission is simulated in the browser. It does not send an email, store submissions on a server, or connect to a backend service.

## Pricing Note

The Free, Pro, and Team prices shown on the page are illustrative values for this project demonstration. They are not confirmation of actual commercial subscription plans.

## Project Structure

The project uses a Vite + React structure. The main application code is in `src/`, with reusable page sections organized under `src/components/`.

The exact component files and folders can be reviewed in the `src/components/` directory.

## Notes

- Include `package.json` and `package-lock.json` so dependencies can be installed consistently.
